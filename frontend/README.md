# EcoFusion RentalCars

React + Vite frontend with a real Firebase Authentication layer and FastAPI session/role enforcement.

## Start

1. `npm install`
2. Copy `.env.example` to `.env` and fill the Firebase Web App configuration.
3. Configure `backend/.env` from `backend/.env.example` or export the same variables in your shell.
4. Run the backend and frontend. On Windows you can use `start-dev.bat` after Firebase is configured.

See `README_REAL_AUTH.md` for the complete Google, email/password, phone/SMS and Admin setup.
