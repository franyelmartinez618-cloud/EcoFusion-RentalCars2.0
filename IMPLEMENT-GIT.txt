EcoFusion RentalCars — Auth/Mobile Security Update

Included in this full project package:
- Google sign-in via signInWithPopup with a single user-initiated popup.
- Deduplicated Firebase -> FastAPI session exchange to avoid duplicate auth POSTs.
- Friendly handling for popup blocked/closed, provider already linked, credential already in use, and recent-login errors.
- Account return-path preservation after authentication.
- Account page with visible logout action.
- Desktop and mobile navbar with Mi cuenta/Iniciar sesión and logout controls.
- Compact EcoFusion symbol on small screens while keeping the full logo on desktop.
- Security panel in the account profile showing email verification and Google-link status.
- User-driven Google account linking through Firebase linkWithPopup.
- First-time backend account creation can send a welcome email through Resend when RESEND_API_KEY and RESEND_FROM_EMAIL are configured server-side. Email delivery never blocks authentication.
- Backend session creation flush fix remains included.

Important:
- Do NOT commit frontend/.env.production or frontend/.wrangler/.
- Do NOT commit the Firebase service-account JSON.
- Keep Firebase Admin and any email API keys only in Railway environment variables/secrets.
- Google OAuth itself provides the provider's anti-abuse controls; phone authentication continues to use Firebase reCAPTCHA. Do not add a fake "I'm not a robot" checkbox.
